# Привет! Я Arcatic 👋

Независимый разработчик и фрилансер. Специализируюсь на Fullstack-разработке современных веб-приложений и автоматизации бизнес-процессов.

### 🚀 Мой основной стек:
* **PWA & Server side:** Разработка кроссплатформенных, устанавливаемых веб-приложений с мощной серверной частью, доступных на любых устройствах (смартфоны, планшеты, ПК). Поддержка Service Workers, оффлайн-режима и синхронизации данных.
* **VBA (Visual Basic for Applications):** Автоматизация задач, написание макросов, разработка скриптов и инструментов для Microsoft Office (Excel, Access).

### 🛠 Технологии и инструменты:
* **Frontend:** HTML5, CSS3, JavaScript / TypeScript
* **PWA Features:** Web App Manifest, Service Workers, Cache API
* **Backend:** Разработка серверной части и API для веб-приложений
* **Office Automation:** VBA, Macros, Электронные таблицы, СУБД
* **Инструменты:** Git, GitHub, VS Code, MS Office

*Свободен для фриланс-заказов и интересных проектов в сфере PWA и VBA!*
